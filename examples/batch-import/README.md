# Batch import samples

- Drag `sample-batch.json` into the page to create four instances. Logo Loop uses the built-in logos; Video PiP remains ready for a manual video upload.
- Drag `sample-batch-with-media.zip` into the page to create a Card Stack and Logo Loop with media already attached.

The ZIP is generated from `sample-batch-with-media/` so its manifest and assets remain easy to inspect and edit.
