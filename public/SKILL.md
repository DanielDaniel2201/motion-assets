# Motions

Motions is a browser-local motion graphics tool. Nothing is uploaded. A user can either select one motion in the web UI, adjust it, and export a transparent MOV, or import a batch generated by an agent.

Use this skill when a user asks for one or more motion graphics, animated overlays, title animations, counters, progress bars, chat animations, card stacks, picture-in-picture video, or logo loops.

## Agent workflow

1. Translate the request into a version 1 batch manifest using the schema below.
2. If no external media is needed, create a `.json` file.
3. If any instance needs images, logos, avatars, or video, create a `.zip` containing `motion-batch.json` and the referenced media files.
4. Give the JSON or ZIP to the user and tell them to drag it onto the Motions page or use the fixed `+` import button.
5. The imported instances remain editable. The user previews them, adjusts parameters if needed, and exports transparent ProRes 4444 MOV files.

Do not invent motion IDs, parameter names, formats, or enum values. Unknown parameters are rejected. Omitted `format` and `parameters` use defaults.

## Manifest schema

```json
{
  "version": 1,
  "instances": [
    {
      "id": "unique-id",
      "name": "Human-readable name",
      "motion": "blur-text",
      "format": "16:9",
      "parameters": {},
      "assets": ["media/example.png"]
    }
  ]
}
```

Rules:

- `version` must be `1`.
- `instances` must contain 1-50 items.
- `motion` is required.
- `id` is optional, unique, non-empty, and at most 80 characters.
- `name` is optional and non-empty.
- `format` is optional: `16:9`, `9:16`, `4:3`, `3:4`, or `1:1`. Default: `16:9`.
- `parameters` is optional. Include only supported keys listed below.
- `assets` is only for ZIP imports and contains paths relative to the manifest's folder. Omit it from plain JSON.
- Colors must be six-digit hex strings such as `#ff0066`.

## External media in ZIP files

Put actual media files in the ZIP and reference each one from the instance's `assets` array. Do not use web URLs, absolute paths, Base64/data URLs, or paths containing `..`.

If `motion-batch.json` is at the ZIP root:

```text
motion-batch.zip
|-- motion-batch.json
`-- media/
    |-- card-front.png
    |-- brand-logo.svg
    `-- demo-video.mp4
```

A reference such as `"assets": ["media/card-front.png"]` resolves to that exact file. Paths are case-sensitive in practice; use forward slashes and make names match exactly.

Media mapping:

- `card-stack`: 2-8 image files. `assets` order is the front/card sequence.
- `chat-dialog`: 0-2 image files. First is the left avatar; second is the right avatar.
- `logo-loop`: 1-12 image or SVG logo files. `assets` order is loop order. Omit `assets` to use built-in logos.
- `video-pip`: 0-1 video file. The first asset is the PiP video.
- `progress-bar`, `blur-text`, and `count-up`: no assets are accepted.

Supported image extensions are `.png`, `.jpg`, `.jpeg`, `.webp`, `.gif`, and `.svg`. Supported video extensions are `.mp4`, `.webm`, and `.mov`. For SVG, include the `.svg` file itself; for video, include the complete local video file. A plain JSON cannot carry media, so omit `assets` and let the user upload missing media in the editor.

## Supported motions

### `card-stack`

Animates 2-8 images as cards.

```json
{
  "animationSpeed": 1,
  "spread": 1,
  "rotation": 1,
  "stagger": 0.12,
  "holdDuration": 1.5
}
```

- `animationSpeed`: 0.6-1.6
- `spread`: 0.65-1.3
- `rotation`: 0-1.5
- `stagger`: 0.06-0.24 seconds
- `holdDuration`: 0.5-3 seconds
- ZIP assets: 2-8 PNG, JPEG, WebP, GIF, or SVG images; each at most 25 MB. Array order is card order.

### `progress-bar`

Animates chapter labels and separators across a timeline. It uses no media.

```json
{
  "duration": 30,
  "separatorThickness": 1,
  "fontSize": 1,
  "fontFamily": "Segoe UI",
  "baseColor": "#ffffff",
  "progressColor": "#000000",
  "chapters": [
    { "id": "intro", "time": 0, "label": "Intro" },
    { "id": "topic", "time": 8, "label": "Topic" }
  ]
}
```

- `duration`: 3-600 seconds
- `separatorThickness`: 0.4-2.2
- `fontSize`: 0.5-2
- `fontFamily`: non-empty string, at most 100 characters
- `chapters`: at most 16 items; each needs a string `id`, a label of at most 24 characters, and a `time` from 0 through `duration`

### `video-pip`

A cursor drags open one video from the upper-left. Without a ZIP asset, the user can upload the video after importing JSON.

```json
{
  "dragDuration": 0.9,
  "videoDuration": 3
}
```

- `dragDuration`: 0.35-2 seconds
- `videoDuration`: 0.05-15 seconds
- ZIP assets: at most one MP4, WebM, or MOV video, at most 200 MB

### `chat-dialog`

Reveals a conversation one message at a time. Optional ZIP assets are left and right avatar images in that order.

```json
{
  "messages": [
    { "id": "message-1", "side": "left", "text": "Did you review it?" },
    { "id": "message-2", "side": "right", "text": "Yes, ship it." }
  ],
  "fontSize": 1,
  "fontFamily": "Microsoft YaHei",
  "messageInterval": 0.9,
  "verticalGap": 0.35,
  "leftAvatarColor": "#000000",
  "rightAvatarColor": "#ffffff",
  "leftBubbleColor": "#000000",
  "rightBubbleColor": "#f2f2f2"
}
```

- `messages`: at most 12; every item needs a string `id`, `side` of `left` or `right`, and text at most 120 characters
- `fontSize`: 0.6-1.6
- `messageInterval`: 0.35-2 seconds
- `verticalGap`: 0-1
- ZIP assets: at most two PNG, JPEG, WebP, GIF, or SVG images; each at most 10 MB

### `blur-text`

Reveals text from blur. It uses no media.

```json
{
  "text": "Bring ideas into focus",
  "duration": 2.5,
  "blur": 22,
  "stagger": 0.12,
  "distance": 0.22,
  "direction": "up",
  "splitBy": "word",
  "fontSize": 1,
  "fontFamily": "Segoe UI",
  "color": "#000000"
}
```

- `text`: at most 120 characters
- `duration`: 1-8 seconds
- `blur`: 4-48
- `stagger`: 0-0.35 seconds
- `distance`: 0-1
- `direction`: `up`, `down`, `left`, or `right`
- `splitBy`: `character`, `word`, or `line`
- `fontSize`: 0.5-1.8

### `count-up`

Animates a formatted number. It uses no media.

```json
{
  "start": 0,
  "end": 1000,
  "duration": 2.5,
  "decimals": 0,
  "separator": true,
  "easing": "ease-out",
  "prefix": "",
  "suffix": "+",
  "fontSize": 1,
  "fontFamily": "Segoe UI",
  "color": "#000000"
}
```

- `start`, `end`: -1,000,000,000,000 through 1,000,000,000,000
- `duration`: 0.5-10 seconds
- `decimals`: integer 0-4
- `separator`: boolean
- `easing`: `ease-out` or `linear`
- `prefix`, `suffix`: at most 8 characters each
- `fontSize`: 0.5-1.8

### `logo-loop`

Loops transparent logos horizontally. If `assets` is omitted, the app uses its built-in ChatGPT, Claude, Grok, and Gemini logos.

```json
{
  "duration": 6,
  "speed": 0.18,
  "logoSize": 0.16,
  "gap": 0.1,
  "fadeEdges": 0.08,
  "positionY": 0.5,
  "direction": "left"
}
```

- `duration`: 2-20 seconds
- `speed`: 0.04-0.5
- `logoSize`: 0.06-0.3
- `gap`: 0.02-0.25
- `fadeEdges`: 0-0.25
- `positionY`: 0.15-0.85
- `direction`: `left` or `right`
- ZIP assets: 1-12 PNG, JPEG, WebP, GIF, or SVG images; each at most 10 MB

## Plain JSON example

```json
{
  "version": 1,
  "instances": [
    {
      "id": "launch-title",
      "name": "Launch title",
      "motion": "blur-text",
      "format": "16:9",
      "parameters": {
        "text": "The future starts now",
        "duration": 2.8,
        "direction": "up",
        "splitBy": "word",
        "color": "#ffffff"
      }
    },
    {
      "id": "launch-number",
      "name": "Customer count",
      "motion": "count-up",
      "format": "1:1",
      "parameters": {
        "start": 0,
        "end": 25000,
        "duration": 3,
        "suffix": "+",
        "separator": true
      }
    }
  ]
}
```

## ZIP example

```text
motion-batch.zip
|-- motion-batch.json
`-- media
    |-- card-1.png
    |-- card-2.png
    `-- logo.svg
```

```json
{
  "version": 1,
  "instances": [
    {
      "id": "cards",
      "motion": "card-stack",
      "format": "9:16",
      "parameters": { "spread": 1.1, "holdDuration": 2 },
      "assets": ["media/card-1.png", "media/card-2.png"]
    },
    {
      "id": "logos",
      "motion": "logo-loop",
      "format": "16:9",
      "assets": ["media/logo.svg"]
    }
  ]
}
```

ZIP rules:

- Include exactly one JSON manifest and preferably name it `motion-batch.json`.
- Use relative forward-slash paths with no `..` segments and no absolute paths.
- Store files uncompressed or use standard Deflate compression; do not encrypt the ZIP.
- Maximum upload and total uncompressed size: 512 MB. Maximum 200 ZIP entries.
- Referenced media must exist and match the motion's media type and size limits.
